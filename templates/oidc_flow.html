Step 0 / 9
1
User Clicks Login
Browser sends GET request to /OIDC/wso2/login
Browser → App
2
App Builds Auth Request
App generates auth URL with client_id, redirect_uri, scope{% if features.get('pkce') %}, and PKCE code_challenge{% endif %}
App → Browser (302)
3
Browser Redirected to WSO2
Browser follows redirect to WSO2 AuthN endpoint with all auth parameters
Browser → WSO2
4
WSO2 Shows Login Form
WSO2 validates request parameters and renders its login page to the user
WSO2 → Browser
5
User Submits Credentials
Browser POSTs username + password to WSO2 for authentication
Browser → WSO2
6
WSO2 Issues Authorization Code
WSO2 redirects browser to redirect_uri with a short-lived code
WSO2 → App (code)
7
App Exchanges Code for Tokens
App POSTs code + client_secret{% if features.get('pkce') %} + code_verifier (PKCE){% endif %} to token endpoint
App → WSO2 (POST)
8
WSO2 Returns Tokens
WSO2 responds with access_token, id_token, and optionally refresh_token
WSO2 → App (tokens)
9
App Fetches UserInfo & Renders Dashboard
App calls /userinfo with access token, merges claims, creates session, redirects to dashboard
App → Browser
